# Firea Celeste Musk — Retro Desktop (PREVIEW)

9:16 · 1080×1920 · 30fps · 30s · 100% motion ad. Ini **preview**, bukan final export.

Template brief untuk projek ini tidak diisi; diandaikan sama seperti projek Firea sebelum ini
(produk Firea Celeste Musk, 9:16, 30s, Sales, 5 foto yang sama).

- Preview: `out/firea-retro-preview.mp4`
- Teks & nama tetingkap: `src/copy.ts` · Timing babak, cue, laluan kursor, SFX: `src/timeline.json`
- Tetingkap/kursor/checkbox (UI retro original & generik): `src/kit.tsx` · Babak: `src/FireaRetro.tsx`
- Audio chiptune + nada antara muka procedural: `scripts/make-audio.mjs`
- Aset: `public/img/1–5.jpg` (salinan bahan asal); font Montserrat + VT323 (OFL)

```
npm install
npm run preview
npm run studio
```
Buang flag `--browser-executable` dalam package.json jika render di komputer sendiri.
